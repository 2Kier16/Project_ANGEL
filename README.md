
# Project A.N.G.E.L.
### Autonomous Neural Guidance & Evolutionary Learning Agent

Project A.N.G.E.L. is a multimodal AI and reinforcement learning architecture developed in Python. It pairs local computer vision and dynamic grid navigation with an autonomous edge-AI reasoning core, neural voice synthesis, and low-latency system-level safety hooks.

---

### Key Capabilities & Architecture

- **Reinforcement Learning Core:** Autonomous grid navigation and obstacle avoidance powered by Q-learning state discretization and dynamic reward decay.
- **Multimodal Edge AI:** Decoupled local inference utilizing Ollama (Llama 3.2) for low-latency reasoning without external cloud dependencies.
- **Neural Voice & Audio Loop:** Asynchronous Edge-TTS voice generation with non-blocking audio buffers.
- **Failsafe System Safety:** Global system-level background listener providing sub-millisecond session termination (`CTRL + ALT + K`).

---

### Technology Stack

- **Languages & Frameworks:** Python 3.12, Pygame-ce, NumPy
- **Machine Learning & AI:** Q-Learning (State-Action Value Iteration), Ollama
- **System & Automation:** Pynput, OpenCV, Edge-TTS
